# Animation Scale：保留动作和尺寸的缩放归一化

## 工具用途与使用

用于处理 UE 导入骨架的固定对象缩放，例如 `(0.01, 0.01, 0.01)`。结果是对象 Scale 为 `(1, 1, 1)`，角色世界尺寸和当前 Action 的动作保持一致。它不会按目标角色身高调整比例，也不执行重定向。

安装 OZO_Tools ZIP 后，在 N 面板打开 OZO_Tools → Animation Scale。选择带当前 Action 的源骨架，点击 Check；信息按钮中会显示适用性检查结果。符合条件时点击 Normalize Scale。界面和报告使用英文。

工具会复制当前 Action、骨架数据和网格数据；新数据以 `_Scale1` 命名。原 Action 保留并设置假用户，以免变成无用户数据后丢失。原 `.blend` 不会自动保存或覆盖。

## 为什么不能只改 Scale 或直接 Ctrl+A

如果对象 Scale 自身有动画曲线，把面板里的 Scale 改成 1，下一次切帧就可能又被曲线写回 0.01。只把 Scale 曲线改成 1，则骨骼和模型的原始坐标仍以原来数值保存，世界尺寸会变大。

此外，应用骨架对象变换并不同时转换姿态位移、动画曲线和约束。因此单独 Ctrl+A → Scale 不能完成本例所需的同步转换。[Blender 官方说明](https://docs.blender.org/manual/de/5.1/scene_layout/object/editing/apply.html)

设原对象均匀缩放为 s，本例 s = 0.01。转换需要同步处理：

| 数据 | 处理 |
| --- | --- |
| 骨架静止数据 | 全部骨骼的静止数据统一乘 s |
| 网格数据 | 全部顶点局部坐标乘 s |
| 骨骼 Location 曲线 | 关键帧数值及左右手柄的 Y 值乘 s |
| 未打关键帧的骨骼 Location | 当前数值乘 s |
| 骨架对象 Scale 曲线 | XYZ 的关键帧和手柄数值全部设为 1 |
| 骨架对象 Scale | 设为 `(1, 1, 1)` |
| 其他变换 | 对象位移和旋转、骨骼旋转和缩放不作数值缩放 |

直观上，原来“局部坐标 100 × 对象缩放 0.01 = 世界长度 1”，转换后成为“局部坐标 1 × 对象缩放 1 = 世界长度 1”。位移动画同样需要转换单位。对均匀缩放，这种单位变换与旋转兼容。

## 支持范围

处理当前活动骨架及其直接子网格，只转换当前 Action。支持任意固定的正均匀比例，不硬编码 0.01；支持多个符合条件的网格，也支持只有骨架、没有网格。

第一版要求：

- 骨架没有对象父级，使用 Pose Position；对象 Delta Transforms 为默认值。
- Action 只有一个槽、一个层和一个关键帧片段，使用 Replace、影响值 1。
- 骨架和网格没有约束、驱动、NLA；不存在外部对象/数据对待转换骨架的额外依赖。
- 网格通过 Object 方式直接挂在骨架下，局部矩阵和父级逆矩阵近似单位矩阵；元素最大偏差允许 `0.00001`，以兼容导入时的浮点残差。保留微小的旋转和缩放残差，平移分量按原缩放值同步换算，不直接清空矩阵。网格只能有一个指向当前骨架的 Armature 修改器，以顶点组形变，不使用包络或多修改器组合。
- 骨架、网格几何数据为本地且不共享；没有形态键、额外物理/实例化、分段 B-Bone 或自定义骨骼形状。
- 动画只包含对象/骨骼的普通 Location、Rotation、Scale 通道；没有 FCurve 修改器、采样曲线、静音通道或其他动画属性。没有修改器和采样点的空通道允许保留。
- 场景不使用时间重映射。完整验证的基准坐标内存不超过 512 MiB。

帧切换回调逐个检查：已核对代码的 AMP Animate Pro 播放回调，在没有播放动画时可以兼容；已核对代码的 Auto-Rig Pro 骨骼层回调，在动态层功能关闭时可以兼容。匹配还检查函数源码指纹，只有名称相同而代码不同的回调不会被直接放行。其他回调会在报告中列出模块和函数名称，并阻止非单位缩放转换。工具不会移除、禁用或调整任何其他插件回调的顺序。

已满足其他检查且 Scale 恒为 1 的数据，Check 会显示 Already Scale 1，Normalize Scale 也直接跳过，不切换帧、不创建新数据。因此不相关的帧回调不会阻止这类无需处理的数据。

不满足条件时，在修改数据前停止并给出具体原因。原始 Action 即使被其他对象使用，也可以通过复制保护；共享几何数据则拒绝处理。

## 如何验证及恢复

转换前采集当前 Action 范围内所有整数帧、非整数关键帧时间，以及当前帧/子帧的基准。转换后逐样本比较：

- 所有骨骼的世界空间头尾位置。
- 所有待处理网格的每一个求值顶点的世界空间位置。
- 骨架对象 Scale 是否始终为 1。

误差阈值为 `0.00002` Blender 世界单位；它不等于界面显示的长度单位，若场景采用其他单位比例，应结合场景单位理解。非常大的坐标或数值不稳定的情况可能无法通过验证。

矩阵是否近似单位矩阵与最终世界误差是两项独立检查。放宽导入矩阵残差检查不会放宽逐帧误差要求；若残差导致动作或顶点偏差超限，仍会回滚。0.5.2 在当前 SK_Mannequin 副本上验证了全部 61 帧、每帧 23,309 个顶点，最大顶点偏差约 `1.81e-6` 世界单位；按 1 世界单位 = 1 米换算约为 0.0018 毫米。

失败时恢复旧骨架、网格、Action、原 Action 的假用户状态、对象缩放、姿态变换通道和帧，并移除本次新建的数据。成功后也恢复原来的当前帧/子帧、模式和选择。操作支持 Undo/Redo。

原 Action 保留作备份；它仍属于原始比例的静止骨架。不要只把旧 Action 指派给归一化后的骨架来“还原”，因为骨架和网格数据也已经换了单位。需要完整还原时使用 Undo 或源文件。工具会检查本工具生成的骨架/Action 配对，防止旧 Action 导致重复转换。若要处理其他未转换的 Action，应从原始骨架副本开始。

## 相同简单结构下的手动操作

下面是与算法对应的界面操作流程，例子使用 s = 0.01。前提仍然是上述简单父子结构；复杂父级、约束、NLA 或形态键不适用。先保存一份单独的测试文件，并关闭 Auto Key，避免操作时意外插入关键帧。

1. **保留原 Action，制作工作副本。** 在 Action Editor 中给原 Action 开启假用户，并复制成新 Action，使新 Action 成为当前 Action。不要直接编辑原 Action。
2. **解除对象缩放曲线的覆盖。** 在副本中仅删除骨架“对象级”的 Scale X/Y/Z 曲线，保留骨骼的 Scale 曲线；随后在对象变换面板把 XYZ Scale 输入为 1。这一步会暂时改变显示尺寸，后续步骤会同步补齐。工具本身采用把这些对象曲线改成恒定 1 的做法，两者在本例中作用相同。
3. **缩小静止骨架数据。** 在 Object Mode 仅选择源骨架，用 Shift+S → Cursor to Selected 将 3D Cursor 放在骨架对象原点，枢轴设为 3D Cursor。进入 Edit Mode，显示并选中全部骨骼，包括隐藏骨骼，执行 `S` → `0.01`。这次只缩放静止骨架数据。
4. **缩小网格数据。** 对每个符合条件的直接子网格，在 Edit Mode 显示并选中全部顶点，以其对象原点为枢轴执行 `S` → `0.01`。在本工具要求的单位局部矩阵、单位父级逆矩阵下，网格原点与骨架原点重合。不要额外缩放网格对象。
5. **缩放骨骼位移动画。** 在 Graph Editor 中仅选中各骨骼的 Location X/Y/Z 曲线及其全部关键帧，排除对象级 Location、所有 Rotation 和 Scale 曲线。关闭 Normalize 曲线显示和比例编辑，将 2D Cursor 的 Y 值设为 0，枢轴选 2D Cursor，执行 `S` → `Y` → `0.01`。Y 在这里代表属性数值，X 是时间；这样按零值缩放位移和手柄，不缩放帧时间。[Graph Editor 官方说明](https://docs.blender.org/manual/en/5.2/editors/graph_editor/introduction.html)
6. **补齐未打帧的位移。** 如果某根骨骼的某个 Location 分量没有曲线，其静态 Location 数值也要乘 0.01；若原值为零则不用调整。保留其旋转和骨骼缩放。
7. **验证整段动画。** 检查全部帧，确认对象 Scale 不再跳回 0.01、模型尺寸和脚底/手部等运动轨迹一致，再另存结果。只有肉眼查看几帧不能替代逐帧数值验证。

这套手动步骤不包含自动复制几何数据、前置结构检查、逐帧数值比较和失败回滚；插件用于把这些步骤一次性完成。

## 本项目真实回归

使用未处理的 Idle 备份，在隔离的 Blender 5.2.2 后台进程中测试，没有改动已处理好的现场或覆盖备份文件。

- 验证范围：1–302 帧，90 根骨骼，每帧全部 7,438 个求值网格顶点。
- 独立对比最大骨骼误差：约 `8.46e-7` Blender 世界单位。
- 独立对比最大顶点误差：约 `1.16e-6` Blender 世界单位。
- 每帧对象 Scale 为 1；原 Action 的关键帧、手柄保持不变。
- 额外验证了小数帧、未打帧位移、多网格、失败回滚、Undo/Redo 和重复执行跳过。
